◆ MORTY's Verdict — All 6 Fonts

06 · Abstract Groovy

MORTY's pick. "Groovy" in the name doesn't mean soft — geometric groovy fonts can hit hard. If it renders with bold, angular letterforms it will complement the Industrial/Raw direction without fighting it. The name suggests it has personality without being precious about it. This is the one I want to see on the hero headline and menu card names.

◆ PURSUE LICENSE · USE FOR DISPLAY
05 · Magic School

Wildcard. Could go anywhere depending on how it renders — if it's the Magic School Bus-inspired font it's playful and fun, which is actually on-brand for a food truck even in an industrial direction. Could work as an accent or secondary display font for badges and labels.

◆ DEPENDS ON RENDER · VERIFY LICENSE
03 · BILLD

The most industrially compatible of the first batch based on name alone — bold condensed display fonts are industrial by nature. Still needs license verification. Strong backup if AbstractGroovy doesn't land.

◆ BACKUP PICK · VERIFY LICENSE FIRST
01 · The Augusta

Beautiful script but fighting the aesthetic. Only works if Jay wants to use it exclusively as the wordmark/logo — not for any other display text.

◆ LOGO ONLY OR SKIP
02 · Magic Funk

Fontalicious fonts trend playful and rounded. Likely too soft for the direction unless the render surprises.

◆ PROBABLY SKIP
04 · Soul Wave (Demo)

Demo version. Missing glyph set means it can't be used in production regardless of aesthetic fit. If it renders beautifully, buy the full version from hanscostudio.com and reassess.
